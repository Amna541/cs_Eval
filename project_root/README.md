
# Group Tracking Dashboard

## Installation:
1. Clone/download the project.
2. Import `track_db.sql` (create the database manually).
3. Edit `config.php` and update database credentials.
4. Start the XAMPP server and access `http://localhost/group_tracking_dashboard`.

## Features:
- Enter contact manually or via Excel upload.
- Generate encrypted tracking links.
- Record link clicks in the database.
- Admin dashboard to track statistics.
